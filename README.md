# WeatherGlass

A beautiful, dark-themed, glassmorphism weather dashboard built with Next.js 14 App Router and Tailwind CSS.

## Features
- Search global cities for real-time weather
- 5-Day forecast with 3-hour interval interactive line charts
- Save your favorite cities locally using localStorage
- Custom Animations using Framer Motion
- Geolocation API support
- Fully Responsive design tailored for Mobile, Tablet, and Desktop

## Setup

1. Clone repository
2. Install dependencies: `npm install`
3. Create a `.env.local` file with your OpenWeather API key:
   `OPENWEATHER_API_KEY=your_key_here`
4. Run development server: `npm run dev`

Open [http://localhost:3000](http://localhost:3000)

## Tech Stack
- Next.js 14 (App Router)
- React 18
- Tailwind CSS 3
- Framer Motion
- Recharts
- Lucide React Icons
